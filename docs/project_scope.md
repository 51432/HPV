# 项目范围与定位（Project Scope）

## 1. 项目定位
本项目定位为：

> **围绕“HPV克隆性整合—局部调控重塑—邻近基因持续激活”主线的机制研究 + 可复现分析框架建设。**

它不是单一的“HPV整合检测工具开发仓库”，而是用于支持以下目标：
- 明确科学问题与可检验假说；
- 形成可执行的文献调研与证据整合流程；
- 搭建多组学机制分析的可复现工作流；
- 逐步沉淀可用于论文与项目汇报的证据链。

## 2. 核心科学问题
1. HPV整合是否会改变整合位点附近的基因组/染色质/顺式调控环境，进而驱动邻近宿主基因持续激活？
2. 整合事件克隆性（clonality index）是否与其局部调控影响强度相关，并在肿瘤演化中受到正向选择？

## 3. 研究边界（In-scope）
- HPV整合事件的标准化整理、注释与克隆性量化；
- 整合位点邻近基因表达异常与距离依赖分析；
- 多组学机制注释（ATAC/染色质开放、增强子、3D结构、CNV/SV等）；
- productive integration 候选定义与优先级排序；
- 机制模型构建、稳健性检验和替代解释排除。

## 4. 非核心边界（Out-of-scope）
- 新整合检测算法的底层方法学创新（可调用已有方法作为输入）；
- 泛化为“所有病毒整合机制”的大综述项目；
- 与主线无关的全基因组无假设探索（除非作为稳健性补充）。

## 5. 主要交付物
- 结构化文献证据库（机制维度可检索）；
- 分析计划与可执行模块说明（输入/输出/方法/风险）；
- 分阶段结果表（整合事件层面、基因层面、机制层面）；
- 可复现文档与图表骨架（支持后续论文写作）。

## 6. 成功判据（阶段性）
- 是否建立可追溯的“整合→调控重塑→表达改变→克隆选择”证据链；
- 是否可在多个样本/队列中复现关键关联；
- 是否能够区分主假说与关键替代假说；
- 是否形成可直接复用的分析框架与标准化文档体系。
