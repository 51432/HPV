# 分析计划（Analysis Plan）

本计划以“生物学问题驱动”为原则，将课题拆分为可执行模块（Aims）。

## Aim 1：HPV整合事件整理与克隆性量化

**目标**  
建立可比较的整合事件级数据库，并给出稳健的克隆性指标。

**核心问题**
- 每个样本有哪些可信整合事件？
- 克隆性如何定义（read support、VAF proxy、copy-number adjusted metrics）？

**输入数据**
- HPV捕获测序/WGS断点信息；
- 样本基础信息（癌种、分期、批次、纯度）；
- CNV与必要的覆盖度统计。

**主要思路**
- 统一事件ID与断点坐标标准；
- 设定QC分层（高可信/候选）；
- 在CN背景下估计相对克隆性指数。

**预期输出**
- `metadata/integration_event_catalog.tsv`
- `results/aim1_clonality_summary.tsv`
- 克隆性分层可视化（样本内/样本间）。

**难点与替代方案**
- 难点：不同检测策略可比性不足；
- 替代：采用“平台内主分析 + 平台间敏感性分析”。

---

## Aim 2：整合位点邻近基因异常表达分析

**目标**  
评估整合附近基因表达升高现象及其稳定性。

**核心问题**
- 邻近基因是否显著上调？
- 上调是否与整合事件属性（克隆性、病毒片段特征）相关？

**输入数据**
- RNA表达矩阵（bulk或其他）；
- 基因注释坐标；
- Aim 1整合事件表。

**主要思路**
- 基于多距离窗口（±50kb/100kb/500kb/1Mb）定义邻近基因集；
- 与匹配背景基因集比较表达偏移；
- 建立回归模型控制CN、纯度、批次等混杂。

**预期输出**
- `results/aim2_local_expression_effect.tsv`
- 邻近基因表达效应图（火山图/雨林图/距离衰减图）。

**难点与替代方案**
- 难点：表达异质性高；
- 替代：采用分层分析（癌种、亚型）与稳健回归。

---

## Aim 3：距离依赖cis-effect与克隆性耦合分析

**目标**  
验证“克隆性越高，局部cis激活效应越强”的关系。

**核心问题**
- 表达效应是否随整合—基因距离衰减？
- 克隆性是否调制该衰减斜率或效应强度？

**输入数据**
- Aim 1克隆性指标；
- Aim 2邻近表达效应；
- 基因组距离与方向信息。

**主要思路**
- 混合效应模型/广义加性模型（GAM）；
- 考察 interaction：distance × clonality；
- 进行置换/bootstrapping验证稳健性。

**预期输出**
- `results/aim3_distance_clonality_models.tsv`
- 关键模型参数与效应图。

**难点与替代方案**
- 难点：统计功效不足；
- 替代：合并外部公开队列或采用贝叶斯层级模型。

---

## Aim 4：调控环境与结构注释（ATAC/增强子/3D/CN/SV）

**目标**  
为候选位点建立机制证据层。

**核心问题**
- 哪些位点伴随开放性增强、增强子重连、边界扰动或CN/SV共现？
- 机制证据是否解释高表达与高克隆性耦合？

**输入数据**
- ATAC/开放染色质数据（如有）；
- 增强子注释、CTCF/TAD注释、Hi-C/HiChIP参考；
- CNV/SV调用结果。

**主要思路**
- 断点邻域多层注释并打分（mechanism evidence score）；
- 区分“整合主导”与“CN/SV主导”两类场景；
- 输出位点级机制标签。

**预期输出**
- `results/aim4_mechanism_annotation.tsv`
- 多轨道证据图与位点报告模板。

**难点与替代方案**
- 难点：同一样本多组学不完备；
- 替代：使用公共图谱做参考注释，并单独标注证据等级。

---

## Aim 5：productive integration筛选与候选驱动位点优先级

**目标**  
综合多维证据识别最可能具有功能驱动意义的整合事件。

**核心问题**
- 如何定义“productive integration”？
- 哪些位点最值得后续实验验证？

**输入数据**
- Aim1–4全部输出；
- 肿瘤相关基因/通路先验知识。

**主要思路**
- 构建综合评分：clonality + expression effect + mechanism score + robustness；
- 建立高/中/低优先级候选清单；
- 形成每个位点的证据卡片（evidence card）。

**预期输出**
- `results/aim5_productive_integration_candidates.tsv`
- `figures/`中候选位点总览图与示意机制图。

**难点与替代方案**
- 难点：评分体系主观性；
- 替代：提供透明权重、敏感性分析与多版本评分。

---

## 实施顺序建议
1. Aim 1 → 2（先构建事件与表型基础）
2. Aim 3（建立主线统计证据）
3. Aim 4（补足机制层证据）
4. Aim 5（形成可验证候选与阶段性结论）
